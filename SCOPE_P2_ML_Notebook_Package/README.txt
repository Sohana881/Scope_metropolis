SCOPE P2 ML notebook package
1. Extract this folder alongside your existing backend files; do not replace main.py.
2. Open SCOPE_P2_ML_Risk_Engine.ipynb in Jupyter or VS Code.
3. Run cells top-to-bottom. Cell 1 installs dependencies; Cell 3 downloads the public dataset.
4. Outputs are saved under data/raw, artifacts, and reports.
5. This is address-level classification, not a direct action-level model. It is not yet API-integrated.
6. No honest 99% guarantee is possible before running and evaluating on the held-out test set.
